# Featherview Homebrew tap

```sh
brew install --cask featherview/tap/featherview
```

[Featherview](https://featherview.mynetx.net) is a fast, keyboard-driven image viewer for macOS
with batch conversion. It isn't notarized by Apple yet, so macOS blocks the first launch: open it
once, then choose System Settings › Privacy & Security › Open Anyway.
